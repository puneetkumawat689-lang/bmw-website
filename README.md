# BMW Website Clone / Portfolio Project

A responsive, visually engaging, and modern UI clone of the BMW website, built as a personal portfolio project. The website features sophisticated scroll animations, integrated video sections, responsive grids, and an elegant dark/light theme approach, showcasing high-level web design capabilities.

## 🎨 Features
- **Modern User Interface**: A pixel-perfect, premium look inspired by the classic BMW brand aesthetic.
- **Scroll Animations**: Smooth entrance animations using the AOS (Animate On Scroll) library.
- **Video Integration**: Features multiple auto-playing videos embedded flawlessly into cards and hero sections.
- **Responsive Layout**: Fully responsive layout designed with Bootstrap 5 to look great on desktop, tablet, and mobile devices.
- **Dynamic Navbar**: A sticky navbar that changes styling based on user scroll behavior.

## 🛠️ Technologies Used
- **HTML5**: Semantic and structural layout.
- **CSS3**: Custom styling, hover effects, overlays, and responsive design.
- **Bootstrap 5 (v5.3)**: CSS framework for flexible grids, cards, and navigation.
- **JavaScript**: For navbar scroll effects and initialization of AOS.
- **AOS Library**: Third-party library for smooth fade and zoom scroll animations.
